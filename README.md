# 🎴 Card Guessing Game

> 🎮 A fun and interactive console-based Java game where you test your luck and logic by guessing randomly generated playing cards.

## ✨ Features

* 🃏 52-card game concept
* ❤️ Multiple lives
* ⭐ Score system
* 🔥 Streak bonus
* 🎯 Random challenges
* 🛡️ Input validation
* 🏆 Final score & player ranking
* 🔄 Replay option
* 💻 Interactive console gameplay

## 🛠️ Technologies

**Java** • **OOP** • **Scanner** • **Random** • **Arrays** • **Loops** • **Methods**

## 🎮 How to Play

1. Start the Java application.
2. The game generates a random card challenge.
3. Enter your guess.
4. Get points for correct answers.
5. Build a streak to earn bonus points.
6. Wrong answers reduce your lives.
7. Continue until the game ends.
8. Check your final score and rank.
9. Choose whether to play again.

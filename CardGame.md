# 🎴 Card Guessing Game

A fun **console-based Java card guessing game** where players test their luck and logic by guessing randomly generated playing cards.

## 🎮 Features

* 🃏 Uses a standard **52-card concept**
* ❤️ Multiple **lives**
* ⭐ Score tracking
* 🔥 **Streak bonus** for consecutive correct guesses
* 🎯 Random card challenges
* 🛡️ Input validation
* 🏆 Final score and player ranking
* 🔄 Replay option
* 💻 Simple and interactive console interface

## 🛠️ Technologies Used

* **Java**
* **Object-Oriented Programming (OOP)**
* `Scanner` for user input
* `Random` for generating random cards
* Conditional statements
* Loops
* Methods
* Arrays
* Exception/input validation concepts

## 🧠 How the Game Works

1. The game generates a random playing card.
2. The player receives a challenge.
3. The player enters their guess.
4. The game checks the answer.
5. A correct answer increases the score and streak.
6. An incorrect answer reduces a life.
7. The game continues until the player runs out of lives or completes the game.
8. A final score and rank are displayed.
9. The player can choose to play again.
